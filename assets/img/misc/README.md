# Misc logos

Small inline logos used before Linus B. Torvalds, Osako Suguru (大迫傑), and Stephen Curry on the homepage.

- `linux-tux.png`: classic Tux image from [kernel.org](https://www.kernel.org/theme/images/logos/tux.png), downloaded 2026-09-16. Original transparent 104 × 120 PNG, unchanged.
- `oregon-project.png`: Nike Oregon Project logo from [Wikipedia](https://en.wikipedia.org/wiki/Nike_Oregon_Project), downloaded 2026-09-16. Original PNG, unchanged.
- `golden-state-warriors.svg`: Golden State Warriors logo from the [NBA's official CDN](https://cdn.nba.com/logos/nba/1610612744/primary/L/logo.svg), downloaded 2026-09-16. The SVG viewBox trims the empty outer margin for consistent inline sizing; the logo paths and colors are unchanged.

The images are stored locally and displayed at 24 × 24 CSS pixels. Edit the names and image references in `_pages/about.md`; spacing and dark-mode styling live in `assets/css/misc-icons.css`.
