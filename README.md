# Jixian Liu — Academic Homepage

A standalone academic homepage repository based on [al-folio](https://github.com/alshedivat/al-folio).

- Local directory: `/home/jixia/JeanLew01.github.io`
- GitHub repository: `JeanLew01/JeanLew01.github.io`
- Website: `https://jeanlew01.github.io`
- Theme source: al-folio `main`, commit `8ec1f3608d997491e0206c4e7a9368547a5ef255`; core gems pinned to `1.0.15`.

The biography, research interests, 6 publications, education and appointments, awards, teaching, academic service, mentoring, and talks are filled in from the September 2026 CV. The navigation is About / Publications / Research / Teaching & Service / CV. The homepage footer links to email, GitHub, Zhihu, Google Scholar, and LinkedIn. The profile photo, preview images for 4 selected publications, and the PDF CV are in place; see [SETUP.md](SETUP.md#3-更新个人资料) for how to update these assets.

## Where to edit

| Content                                | File                         |
| -------------------------------------- | ---------------------------- |
| Name, site URL, theme toggles          | `_config.yml`                |
| Biography, affiliation, research areas | `_pages/about.md`            |
| Email, Google Scholar                  | `_data/socials.yml`          |
| Publication BibTeX                     | `_bibliography/papers.bib`   |
| Research overview                      | `_pages/research.md`         |
| Teaching and service                   | `_pages/teaching-service.md` |
| Online CV                              | `_data/cv.yml`               |
| Profile photo                          | `assets/img/`                |
| PDF CV                                 | `assets/pdf/`                |

See [SETUP.md](SETUP.md) for creating the remote repository, first-time publishing, and local preview. The full theme documentation is kept in [docs/](docs/README.md).
